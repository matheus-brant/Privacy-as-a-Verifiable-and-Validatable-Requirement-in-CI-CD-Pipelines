# Data availability and restrictions

**Included:** study protocol workbooks, methodological walkthroughs, interface screenshots, and the supplied R Markdown source.

**Not included:** ATLAS.ti QDPX project, interview transcripts, participant-level data, dissertation LaTeX method/appendix source files, and R input spreadsheets that were not provided. The QDPX was inspected only as a consultation source and is intentionally excluded.

Before publication, review every screenshot for interview text, account names, emails, source identifiers and other personal or confidential information. Public availability of an interview-derived visualization does not imply consent to publish raw excerpts. Share only approved anonymized or aggregated inputs.
