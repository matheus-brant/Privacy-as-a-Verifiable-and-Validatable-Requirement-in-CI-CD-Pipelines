# Replication and verification checklist

- Confirm protocol version and all database-specific strings, date limits and search-field restrictions.
- Preserve exported search records, duplicate-resolution decisions, eligibility decisions and reviewer judgments when legally shareable.
- Record Parsifal software version and search dates; distinguish initial from updated retrieval.
- For the interview stage, document recruitment, informed consent, anonymization, interview guide, coding and theme development without releasing identifiable data.
- Preserve ATLAS.ti version and the provenance of screenshots; screenshots show documented project states, not necessarily the original timing of actions.
- Record R/RStudio versions and package versions; enumerate required Excel inputs and columns, and run R Markdown end to end after supplying approved data.
- Validate output filenames and numerical summaries against the dissertation before public release.

A documented procedure is not equivalent to access to restricted data, and reflexive thematic analysis does not require independently generated identical themes.
