# Stage 2 — Reflexive thematic analysis

The qualitative stage combined convenience access with intentional participant selection. Ten initial interviews were complemented by six additional interviews to address research-question coverage. The documented corpus contains 16 anonymized transcripts.

ATLAS.ti procedure: inspect project and document groups; read interviews in context; select quotations and assign descriptive codes; verify quotation-code relationships; review the codebook and comments; group codes by SRQ and retain additional findings; examine the 35 thematic groups and return to the source text to support interpretation.

The source QDPX project and raw interviews are **not shared**. No automated coding or deterministic theme generation is claimed. Counts describe the software project, not statistical significance.
